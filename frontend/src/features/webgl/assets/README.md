# WebGL Demo Assets

The castle scene for the WebGL demo, from [webgl-hogwarts](https://github.com/zach-youssef/webgl-hogwarts). `hogwarts.json` is the scene graph, and names the meshes and textures beside it; `camerapath.txt` is the plane's path.

The grey brick texture was scaled down from 8192 to 2048 pixels square.
